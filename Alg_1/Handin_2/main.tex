\subsection*{Convince God that there doesn't exist some integer $r$ and $s$ so $ 50 = 175 \cdot r + 63 \cdot s$}
Corollary 3.5~\cite{Algebra}\\
For some numbers $a,b \in \mathbb{Z}$ that are not both zero, if $d = \gcd(a,b)$, then there is some integers $r$ and $s$ so 
that $d = ar + bs$ if and only if $d|c$.\\
This means there should exist some integer $q$ such that $50 = 7q$. Sadly $\frac{50}{7} \notin \mathbb{Z}$ which means $q$ doesn't exist and this follows that $r$ and $s$ don't exist either.
